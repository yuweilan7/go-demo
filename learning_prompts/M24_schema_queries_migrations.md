## 必须讲解、实现和观察的内容

1. 从订单列表和唯一请求表出发说明 NOT NULL/default、NULL 与缺值、unique/idempotency key、外键/业务约束、utf8mb4/collation、int/DECIMAL/time 映射；金额与用户 ID 的错误类型通过真实写读暴露，不只展示 DDL。

2. 用有界合成数据与 EXPLAIN 分析联合索引/最左前缀、排序、函数/隐式转换造成的计划变化、过多回表；EXPLAIN ANALYZE 如会执行查询须明确其行为，不对真实业务写语句做实验。

3. offset 分页与 keyset 分页分别观察同排序值、并发插入和页间重复/漏数据；定义稳定 tie-breaker 和分页契约。SELECT *、无界批量读与 N+1 用结果/查询计数定位。

4. 实现可重复执行且可核对的独占 schema migration：版本表、向前兼容的 expand/contract、先兼容再收紧约束。解释 MySQL 某些 DDL 的隐式提交与锁，不能以普通事务 rollback 假装撤销迁移。

5. 验收精度/NULL/字符、唯一键、计划证据、稳定分页与一条前后版本兼容迁移。练习：选择复合索引；修复排序不稳定；评审删除字段的发布顺序。复制、分片、在线 DDL 工具原理按需延后。
