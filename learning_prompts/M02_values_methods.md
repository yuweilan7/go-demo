## 必须讲解、实现和观察的内容

1. 用订单对象的修改解释 Go 参数始终传值：T 复制值、*T 复制地址值、含 slice/map/指针字段的 struct 只复制这些字段的值。用地址、字段和调用后的状态区分顶层复制与内部共享；不能说 Go 存在 Java 式的引用传参。

2. 演示值/指针接收者、自动取址/解引用的适用位置、地址不可取的 map 元素、方法值与方法表达式的绑定时机。说明何时应统一指针接收者，而非凭性能口号决定。

3. 演示返回局部变量地址安全、new/make 的对象类别及零值可用性；按当前 Go 文档核验 new 表达式初始化的新写法，保留读旧代码所需形式。栈/堆属于编译器优化，不能从 new 或 & 直接断言。

4. 用含 sync.Mutex 的 Counter 复现值接收者/拷贝破坏保护边界，使用 vet copylocks 和状态断言定位；明确首次使用后不能复制哪些同步对象。nil *T 能进入方法不等于方法必然安全，给带守卫与无守卫的对照。

5. 练习：预测三个修改函数结果；修复复制锁的值接收者；审查含 slice 字段的 DTO 克隆是否隔离。验收必须能画出值和共享对象的关系，深度 GC 原理留 M35。
