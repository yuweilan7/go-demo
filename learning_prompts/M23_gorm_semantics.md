## 必须讲解、实现和观察的内容

1. 使用同一类合成业务但独立表，把 database/sql 的明确事务迁到真实 GORM；先教现网常见传统 API，再展示实际版本 generics API，不能混用返回值/错误约定。不用 ORM 成功运行掩盖底层 SQL。

2. 复现 Updates(struct) 跳过零值、false/0 更新失效、缺条件/全表更新风险、First/Find 的 not found 差异、Error 与 RowsAffected 不查、复用有条件的 *gorm.DB 造成条件污染；展示参数化 SQL 与修复后的结果。

3. 读 Transaction callback、Begin/Commit/Rollback、WithContext、Session/Scopes 及实际连接传递，复现 tx callback 里用了外层 db、吞 error 返回 nil、panic 被内层恢复成成功。与 M21 的逐行断言对照，默认单条写事务不等于整段业务事务。

4. 用软删除、关联 preload/N+1、分页和 hook 演示隐藏行为：hook 必须明确使用哪个 tx，不能在未提交 hook 里向 MQ 发不可回滚事件。AutoMigrate 仅在独占教学 schema 使用，线上演进由 M24 管理。

5. 验收真实 SQL、正确零值、归属过滤、回滚、panic、context 超时与可解释的行数；日志做脱敏。练习：还原链式调用 SQL；修复漏用户条件和零值更新；解释 hook 成功但事务回滚后的外部事件。
